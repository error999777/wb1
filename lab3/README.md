## Контрольные вопросы

1. Типы селекторов: универсальный `*`, по тегу `p`, классу `.post`, ID `#first-post`, атрибуту `[href="#"]`, псевдоклассы `:hover`, псевдоэлементы `::after`, комбинации с отношениями. Класс может повторяться; ID должен быть уникальным. Специфичность ID выше, чем класса.
2. `*` выбирает все элементы. Полезен для общих правил, например `box-sizing: border-box`. Он имеет нулевую специфичность.
3. Псевдокласс описывает состояние или положение элемента: `:hover`, `:focus-visible`, `:nth-child(2)`. Псевдоэлемент выделяет часть или создаёт декоративный фрагмент: `::placeholder`, `::before`, `::after`.
4. `input[placeholder="Белый"]` выбирает input с точным значением атрибута. `input[placeholder="Белый"]::placeholder` окрашивает именно подсказку, а не введённое значение.
5. `ul li` выбирает все li внутри ul на любой глубине. `h2 + p` выбирает только p непосредственно после h2 с тем же родителем; `h2 ~ p` — все последующие соседние p. `ul > li` выбирает только непосредственных детей.
