# Лабораторная работа №3 — Селекторы CSS

`index.html` сохраняет HTML-структуру, классы, идентификаторы и тексты примера из методички. Раскрашивание выполнено во внешнем `style.css`: без `style`-атрибутов и без JavaScript. Белый placeholder находится на тёмном фоне; текст кнопки и выделенного пункта — чёрный.

Внутри PDF заголовок ошибочно содержит №4; в репозитории работа обозначена №3 по имени методички.

В `style.css` отмечены все восемь требуемых групп: универсальный, теговый, класс, идентификатор, атрибут, псевдоклассы/псевдоэлементы, потомки, соседний элемент.

Дополнительное задание: `business-card.html`, `business-card.css`, `assets/timofey.png`. Это одна секция сайта-визитки без меню: ФИО и профессия в H1, специализация в H2, короткое описание, ссылка на профиль GitHub и фотография. Макет: текст слева, фото справа; на узком экране фото находится под текстом. Переход ко второй секции в методичке указан как необязательный.

## Контрольные вопросы

1. Типы селекторов: универсальный `*`, по тегу `p`, классу `.post`, ID `#first-post`, атрибуту `[href="#"]`, псевдоклассы `:hover`, псевдоэлементы `::after`, комбинации с отношениями. Класс может повторяться; ID должен быть уникальным. Специфичность ID выше, чем класса.
2. `*` выбирает все элементы. Полезен для общих правил, например `box-sizing: border-box`. Он имеет нулевую специфичность.
3. Псевдокласс описывает состояние или положение элемента: `:hover`, `:focus-visible`, `:nth-child(2)`. Псевдоэлемент выделяет часть или создаёт декоративный фрагмент: `::placeholder`, `::before`, `::after`.
4. `input[placeholder="Белый"]` выбирает input с точным значением атрибута. `input[placeholder="Белый"]::placeholder` окрашивает именно подсказку, а не введённое значение.
5. `ul li` выбирает все li внутри ul на любой глубине. `h2 + p` выбирает только p непосредственно после h2 с тем же родителем; `h2 ~ p` — все последующие соседние p. `ul > li` выбирает только непосредственных детей.
