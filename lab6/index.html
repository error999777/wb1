Контрольные вопросы

  1. Количество и ширину столбцов задаёт grid-template-columns. Например, repeat(3, 1fr) создаёт три равных столбца.

  2. Можно задать одинаковые доли fr. При 1fr 1fr две дорожки получают поровну свободного места.

  3. Функция repeat() с auto-fit или auto-fill подбирает число дорожек. В minmax(160px, 1fr) первое значение задаёт минимальную ширину, а второе позволяет столбцу растянуться.

  4. gap задаёт промежутки между элементами. Можно задать их по отдельности с помощью row-gap и column-gap.

  5. grid-column: span 2 растягивает элемент на два столбца, а grid-row: span 2 на две строки. Ещё можно указать номера линий, например grid-column: 1 / 4.

  6. В примере на web.dev цветные карточки перестраиваются при изменении ширины окна. Когда места мало, часть карточек уходит на следующую строку.
